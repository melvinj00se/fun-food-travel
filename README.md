# Fun, Food & Travel

A phone web app: pick photos and videos from a trip, and Claude (by Anthropic) finds the
location, the products in them, nearby hotels, restaurants, car rentals and tours, and
current local news, each with links to shop or book.

**Open it:** https://melvinj00se.github.io/fun-food-travel/

- Runs entirely in the phone's browser. No server and nothing to install.
- Uses your own Anthropic API key, which you enter in Settings. It is stored only on
  your phone and sent only to Anthropic. Type `demo` instead to try it without a key.
- Posts, including their photos and videos, are saved only on your phone.
- Install it: on iPhone (Safari) tap Share, then **Add to Home Screen**. On Android
  (Chrome) tap ⋮, then **Install app**.
